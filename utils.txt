================================================================================
  NGONI IA SERVICE  --  LANCEMENT (Docker)
================================================================================
  Dossier : C:\DEV\NGONI\ngoni-ia-service
  Prérequis : Docker Desktop installé.


--------------------------------------------------------------------------------
  1. ALLUMER
--------------------------------------------------------------------------------

  Double-clic : scripts\demarrer-live.cmd

  ou :

docker desktop start
Set-Location C:\DEV\NGONI\ngoni-ia-service
docker compose up -d
docker compose logs -f prechauffage

  Prêt quand « prechauffage termine » s'affiche (3 à 6 min). Ctrl+C pour
  quitter l'affichage, les serveurs continuent de tourner.


--------------------------------------------------------------------------------
  2. ÉTEINDRE
--------------------------------------------------------------------------------

  Double-clic : scripts\arreter-live.cmd

  ou :

Set-Location C:\DEV\NGONI\ngoni-ia-service
docker compose stop
docker desktop stop


--------------------------------------------------------------------------------
  3. SE CONNECTER
--------------------------------------------------------------------------------

  http://localhost:5173  ->  page de connexion (comptes en un clic)

  Identifiant      Rôle            Mot de passe   Ouvre
  adou             client          ngoni2026      le chat
  awa.kone         conseiller      ngoni2026      le poste conseiller
  yao.kouassi      conseiller      ngoni2026      le poste conseiller
  fatou.diarra     administration  ngoni2026      l'administration

  Démonstration rejouée (sans connexion) : http://localhost:5173/?demo=1#/chat
  API du moteur : http://localhost:8000/docs


--------------------------------------------------------------------------------
  4. COMPTE DE DÉMONSTRATION (avant chaque passage)
--------------------------------------------------------------------------------

docker compose exec fastapi python scripts/compte_demo.py reinitialiser
docker compose exec fastapi python scripts/compte_demo.py afficher

  reinitialiser : vérification d'identité refusée, solde 45 000 FCFA,
  aucun historique. Parcours complet : DEMO-JURY.md.


--------------------------------------------------------------------------------
  5. VÉRIFIER
--------------------------------------------------------------------------------

docker compose ps
Invoke-RestMethod http://localhost:5005/status


--------------------------------------------------------------------------------
  6. APRÈS UNE MODIFICATION DU CODE
--------------------------------------------------------------------------------

docker compose up -d --build fastapi frontend
docker compose restart actions
docker compose restart rasa

  fastapi : moteur + services wallet / user. actions : rasa\actions.
  rasa : rasa\components et rasa\config.yml.

  Réentraîner Rasa (après modification de rasa\data ou rasa\domain.yml, ~5 min) :

docker compose exec rasa rasa train --out models
docker compose restart rasa


--------------------------------------------------------------------------------
  7. SAUVEGARDER LA BASE
--------------------------------------------------------------------------------

docker compose exec postgres pg_dump -U postgres -d chatbotdb -Fc -Z 9 -f /tmp/chatbotdb.dump
docker compose cp postgres:/tmp/chatbotdb.dump docker/postgres/chatbotdb.dump


--------------------------------------------------------------------------------
  8. NOUVEAU POSTE (une seule fois)
--------------------------------------------------------------------------------

Copy-Item .env.example .env
docker compose up -d --build

  Avant : renseigner .env, placer chatbotdb.dump dans docker\postgres\ et
  copier rasa\models\ (le modèle entraîné n'est pas dans git).
  Le premier lancement télécharge images et modèles (~2 Go, 20 à 40 min).
