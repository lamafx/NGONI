============================================================
 NGONI IA SERVICE -- Lancement des serveurs (PowerShell)
 Racine du depot : C:\DEV\NGONI\ngoni-ia-service
 Ordre de demarrage : Postgres -> Rasa -> Moteur -> Stubs -> Frontend
 (le moteur attend que Rasa reponde avant de finir son demarrage)
============================================================

 Ports utilises
   5432  PostgreSQL (service Windows natif)
   5005  Rasa                    (Docker)
   5055  Serveur d'actions Rasa  (Docker)
   8000  Moteur FastAPI          (natif, venv)
   3103  wallet_stub             (natif, meme venv)
   3104  user_stub               (natif, meme venv)
   5173  Frontend Vite           (natif, npm)

 Chaque serveur natif occupe SA propre fenetre PowerShell : les commandes
 ci-dessous ne rendent pas la main. Voir le paragraphe 6 pour tout lancer
 d'un coup dans des fenetres separees.


# ============================================================
# 0. INSTALLATION -- une seule fois
# ============================================================

Set-Location C:\DEV\NGONI\ngoni-ia-service\fastapi
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Copy-Item rasa\.env.example rasa\.env

Set-Location C:\DEV\NGONI\ngoni-ia-service\frontend

# 2. RASA + SERVEUR D'ACTIONS -- Docker
# ============================================================

# `fastapi` du docker-compose : ils entreraient en concurrence avec les

# ============================================================
# 6. TOUT LANCER D'UN COUP -- une fenetre par serveur
# ============================================================
# A coller dans une seule console PowerShell, apres avoir demarre Docker
# Desktop. Chaque Start-Process ouvre une fenetre qui reste ouverte (-NoExit)
# et que l'on ferme avec Ctrl+C.

Set-Location C:\DEV\NGONI\ngoni-ia-service
docker compose up -d rasa actions

$racine  = "C:\DEV\NGONI\ngoni-ia-service"
$python  = "$racine\fastapi\.venv\Scripts\python.exe"

Start-Process powershell -ArgumentList "-NoExit","-Command","Set-Location '$racine\fastapi'; & '$python' -m uvicorn wallet_stub.main:app --app-dir '$racine\fastapi' --port 3103"
Start-Process powershell -ArgumentList "-NoExit","-Command","Set-Location '$racine\fastapi'; & '$python' -m uvicorn user_stub.main:app --app-dir '$racine\fastapi' --port 3104"
Start-Process powershell -ArgumentList "-NoExit","-Command","Set-Location '$racine\fastapi'; & '$python' -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000"
Start-Process powershell -ArgumentList "-NoExit","-Command","Set-Location '$racine\frontend'; npm run dev"


# ============================================================
# 7. VERIFICATIONS
# ============================================================

# Qui ecoute quoi (rien affiche = serveur non demarre)
Get-NetTCPConnection -State Listen -LocalPort 5432,5005,5055,8000,3103,3104,5173 |
  Select-Object LocalPort, OwningProcess | Sort-Object LocalPort

# Rasa a bien charge un modele -> model_file non vide
Invoke-RestMethod http://localhost:5005/status

# Moteur operationnel -> liste non vide si les stubs tournent
Invoke-RestMethod http://localhost:8000/diagnostic/capabilities

# Stubs joignables -> manifeste JSON
Invoke-RestMethod http://localhost:3103/api/v1/diagnostic/manifest
Invoke-RestMethod http://localhost:3104/api/v1/diagnostic/manifest

# Statistiques admin (route protegee : secret = ADMIN_INTERNAL_SECRET du .env)
Invoke-RestMethod http://localhost:8000/admin/stats/overview `
  -Headers @{ "X-Internal-Secret" = "dev-admin-secret-change-me" } |
  Select-Object -ExpandProperty kpis

# Le frontend passe bien par son proxy jusqu'au moteur
Invoke-WebRequest "http://localhost:5173/engine/faq/" -UseBasicParsing |
  Select-Object StatusCode
