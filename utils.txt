================================================================================
  NGONI IA SERVICE  --  LANCEMENT (Docker)
================================================================================
  Dossier : C:\DEV\NGONI\ngoni-ia-service
  Prérequis : Docker Desktop installé.


--------------------------------------------------------------------------------
  1. ALLUMER
--------------------------------------------------------------------------------

  Double-clic : scripts\demarrer-live.cmd

  ou :

docker desktop start
Set-Location C:\DEV\NGONI\ngoni-ia-service
docker compose up -d
docker compose logs -f prechauffage

  Prêt quand « prechauffage termine » s'affiche (3 à 6 min). Ctrl+C pour
  quitter l'affichage, les serveurs continuent de tourner.


--------------------------------------------------------------------------------
  2. ÉTEINDRE
--------------------------------------------------------------------------------

  Double-clic : scripts\arreter-live.cmd

  ou :

Set-Location C:\DEV\NGONI\ngoni-ia-service
docker compose stop
docker desktop stop


--------------------------------------------------------------------------------
  3. ADRESSES
--------------------------------------------------------------------------------

  Chat client (compte de démo)   http://localhost:5173/?compte=a40e0e00-2006-4514-8000-000000000001#/chat
  Poste conseiller               http://localhost:5173/#/agent/live
  Administration                 http://localhost:5173/#/admin
  Démonstration rejouée          http://localhost:5173/?demo=1#/chat
  API du moteur                  http://localhost:8000/docs


--------------------------------------------------------------------------------
  4. COMPTE DE DÉMONSTRATION
--------------------------------------------------------------------------------

docker compose exec fastapi python scripts/compte_demo.py creer
docker compose exec fastapi python scripts/compte_demo.py reinitialiser
docker compose exec fastapi python scripts/compte_demo.py afficher
docker compose exec fastapi python scripts/compte_demo.py creer --nouveau

  reinitialiser : remet le compte dans son état de départ (à faire avant
  chaque passage). creer --nouveau : un compte supplémentaire, son adresse
  de chat est affichée. Parcours complet : DEMO-JURY.md.


--------------------------------------------------------------------------------
  5. VÉRIFIER
--------------------------------------------------------------------------------

docker compose ps
Invoke-RestMethod http://localhost:8000/admin/system/health -Headers @{ "X-Internal-Secret" = "dev-admin-secret-change-me" } | Select-Object -ExpandProperty services


--------------------------------------------------------------------------------
  6. APRÈS UNE MODIFICATION DU CODE
--------------------------------------------------------------------------------

docker compose up -d --build fastapi frontend
docker compose restart actions
docker compose restart rasa

  fastapi : moteur + services wallet / user. actions : rasa\actions.
  rasa : rasa\components et rasa\config.yml.


--------------------------------------------------------------------------------
  7. NOUVEAU POSTE (une seule fois)
--------------------------------------------------------------------------------

Copy-Item .env.example .env
docker compose up -d --build

  Avant : renseigner .env et placer chatbotdb.dump dans docker\postgres\.
  Le premier lancement télécharge images et modèles (~2 Go, 20 à 40 min).
